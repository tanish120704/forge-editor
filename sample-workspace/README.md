# A place to build

Welcome to your first Forge workspace.

## Make yourself at home

- Open `src/app.ts` and try an edit.
- Press **⌘S** to save to your real filesystem.
- Press **⌘P** to jump between files.
- Press **⌘⇧P** to run a command.
- Search across your project with **⌘⇧F**.
- Open your own project with **⌘O**.

The integrated terminal is a real shell, running in this folder.
Try `pwd` or `ls` to look around.

## Built for the essentials

Monaco provides syntax highlighting, completion, folding, multi-cursor
editing, find/replace, and formatting. Forge adds local workspaces,
tabs, file search, a command palette, and a terminal.

This is an independent editor prototype, not a full VS Code distribution.
